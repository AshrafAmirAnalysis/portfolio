# Ashraf Amir

Trust & safety investigator who builds tools. I automate the repetitive parts of
investigation work so people can spend their time on decisions, and I put clear
guardrails around AI agents so their work can be checked.

## Projects

### [Case Copilot](case-copilot.md)
A Chrome extension that runs CRM case handling end to end (notes, replies, customer
email, field macros, closure) through the platform's client and Web APIs, with safety
guards before every write and 350+ automated tests.

### [Investigation Studio](Investigation-studio.md)
A local web app for an AI investigation agent: per-turn least-privilege tool access,
read-only data, human approval before any document is written, and a live audit
trail of every query.

## How I work
- **AI-assisted development.** I design, specify and verify; I build with Claude Code
  as a pair programmer.
- **Testing without a sandbox.** Mock the platform API, test every flow, then verify
  carefully in live use.
- **Safety first.** Identity checks before writes, denylists learned from incidents,
  humans approve anything that leaves the tool.
